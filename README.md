# pop-setup

Automatisierter Umstieg dieses Laptops auf Pop!_OS 24.04 (NVIDIA) neben Windows 11.

- `FORTSCHRITT.md`: Stand der Dinge. Zuerst lesen.
- `INSTALL.md`: die Handgriffe für die Installation selbst.
- `setup.sh`: richtet nach der Installation alles ein. Mehrfach startbar, überspringt Erledigtes.

Enthält absichtlich keine Schlüssel, Seriennummern oder Zugangsdaten.
